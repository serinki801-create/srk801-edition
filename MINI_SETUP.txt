БЕЗОПАСНОСТЬ / ОТКАТ
------------------------------------------------------------
Ядро, драйверы, firmware, GRUB — НЕ ТРОНУТЫ. Всё в $HOME,
~/.config, ~/.local, ~/.bashrc. Перезагрузка не нужна.
Откат:  bash mint_ios_setup.sh --uninstall
Вернёт стандартный вид Mint (темы Mint-Y-Dark/Mint-Y/DMZ-White)
и удалит theos, ios_projects, lite-xl-конфиги, picom.conf,
plank-автостарт. Apt-пакеты (plank/picom/geany) остаются —
удаляются вручную: sudo apt remove plank picom geany.

ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ
------------------------------------------------------------
- Нужен sudo для apt (plank/picom/geany/clangd). Без sudo скрипт
  пропускает системные пакеты с WARN и продолжает остальное.
- Host-Swift НЕ ставится по умолчанию (нужен флаг --with-swift,
  качает ~500+ МБ через swiftly с swift.org). Для .ipa не нужен:
  iOS-Swift берётся из тулчейна Theos при ответе 'y'.
- Первая сборка тянет ~400+ МБ (тулчейн + SDK), занимает 10-20 мин
  на слабом железе; повторные прогоны быстрые (всё кэшируется).
- .ipa подписан ad-hoc (ldid -S): ставится на джейл или через
  AltStore/Sideloadly с переподписью, 7 дней на бесплатном Apple ID.
