 FULL ИНСТРУКЦИЯ: Arch Linux -> вид как macOS -> сборка .ipa
================================================================================
 Всё нужное лежит рядом с этим файлом, в /home/abzal/hobby-os/:
   setup_host.sh, run_xcode_container.sh, setup_macos_ui.sh,
   setup_ios_toolchain.sh, full_macos_setup.sh, arch_macos_build.sh,
   IPA_BUILD_GUIDE.md, PROJECT_SUMMARY.txt
 Ничего скачивать «от меня» не надо — забираешь эти файлы к себе и
 выполняешь шаги ниже НА СВОЁМ Arch Linux (здесь был только конструктор).

--------------------------------------------------------------------------------
ШАГ 0. ЧТО НУЖНО ЖЕЛЕЗНО (проверь до старта)
--------------------------------------------------------------------------------
 - ПК/ноутбук с Arch Linux (скрипты только под Arch, на Mint/Ubuntu не встанут)
 - Intel с VT-x (проверить: grep -E 'vmx|svm' /proc/cpuinfo)
 - 8+ ГБ RAM и 50+ ГБ свободно на SSD (образ macOS ~20 ГБ + Xcode ~15 ГБ)
 - Интернет (качаются гигабайты Apple-инструментов — это неизбежно)
 - Apple ID (для Xcode), а для публикации в App Store — платный Developer ($99)

--------------------------------------------------------------------------------
ШАГ 1. ПОДГОТОВКА ХОСТА (один раз)
--------------------------------------------------------------------------------
 bash setup_host.sh --theme
   - проверит виртуализацию, включит KVM
   - поставит docker, qemu, libvirt, virt-manager, xorriso
   - добавит тебя в группы docker/libvirt, включит службы
   - --theme: оформит Arch под macOS (WhiteSur из исходников + Plank)
 После этого ПЕРЕЗАЙДИ в сессию (группы подхватятся) и проверь:
   docker run --rm hello-world

--------------------------------------------------------------------------------
ШАГ 2. ВЫБЕРИ СВОЙ ПУТЬ СБОРКИ .ipa (один из двух)
--------------------------------------------------------------------------------
 ПУТЬ А — настоящий Xcode (для App Store / TestFlight):
   bash run_xcode_container.sh start --gui   # первый раз: установка macOS
   # ставишь macOS, создаёшь пользователя, включаешь Remote Login,
   # ставишь Xcode из App Store, открываешь его один раз
   ssh-copy-id -p 50922 user@127.0.0.1
   bash run_xcode_container.sh start         # дальше — всегда headless
   bash run_xcode_container.sh build ~/ios_projects/MyApp MyApp Release TEAMID
   # готовый .ipa: ~/ios_projects/build/ipa-<дата>/
   Подробности: IPA_BUILD_GUIDE.md, Способ A.

 ПУТЬ Б — нативно, без виртуалок (для джейлбрейка / AltStore / тестов):
   bash setup_ios_toolchain.sh
   # ставит Theos + iPhoneOS.sdk + Swift-тулчейн + подпись rcodesign,
   # генерирует ~/ios_projects/HelloHybrid и сам его собирает
   cd ~/ios_projects/HelloHybrid
   make package FINALPACKAGE=1
   # готовый .ipa: packages/*.ipa (путь напечатает сам скрипт)
   Подробности: IPA_BUILD_GUIDE.md, Способ B.
   В App Store такой .ipa НЕ примут — туда только Путь А.

--------------------------------------------------------------------------------
ШАГ 3. ВИЗУАЛ И ЖЕЛЕЗО (по желанию, для ноутбука типа ASUS X555L)
--------------------------------------------------------------------------------
 Вариант лёгкий (старые ноуты, 4 ГБ RAM):
   bash setup_macos_ui.sh --dm        # XFCE + WhiteSur + Plank
 Вариант «всё сразу»:
   bash full_macos_setup.sh --yes     # визуал + Lite XL + linux-zen +
                                      # zram + TLP + Firefox под Safari
 Флаги: --de=kde (красивее, но тяжелее), --dm (экран входа),
        --autocpufreq (вместо TLP), --no-bt (выкл. bluetooth).
 После смены ядра — перезагрузка с выбором linux-zen.
 Отдельная сборка своего ISO: bash arch_macos_build.sh (в ISO уже
 входит Firefox, интернет через networkmanager).

--------------------------------------------------------------------------------
ЧАСТЫЕ ВОПРОСЫ
--------------------------------------------------------------------------------
 - Safari на Linux? Его нет в природе. Ставится Firefox, оформленный
   под Safari (full_macos_setup.sh делает это сам).
 - Xcode на Linux? Нет. Либо macOS в Docker (Путь А), либо нативный
   Theos (Путь Б), либо облако (EAS Build / Codemagic).
 - Бесплатный Apple ID? Хватит для тестов (AltStore ставит на 7 дней).
   Публикация и ad-hoc для чужих девайсов — только платный Developer.
 - Monterey тянет Xcode максимум 14.x (SDK до iOS 16). Нужен SDK новее —
   пересобери контейнер на Ventura/Sonoma (тяжелее для старых Intel).
 - Что-то упало? Смотри лог выше места падения + раздел troubleshooting
   в IPA_BUILD_GUIDE.md. Проверка синтаксиса всех скриптов: make check.
